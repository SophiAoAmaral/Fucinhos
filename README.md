# 🐾 Fucinhos

O **Fucinhos** é uma aplicação web desenvolvida em **React** que simula a contratação de um plano de saúde para pets. O projeto foi criado com foco em proporcionar uma experiência simples, intuitiva e moderna, permitindo cadastrar pets, escolher um plano e finalizar a contratação.

##  Funcionalidades

- Cadastro de um ou mais pets.
- Cadastro do responsável.
- Upload de foto do pet.
- Escolha entre planos mensais e anuais.
- Desconto automático de **15%** para o segundo pet em diante.
- Resumo do pedido atualizado em tempo real.
- Simulação de pagamento.
- Interface responsiva.

##  Tecnologias

- React
- React Router
- JavaScript
- Tailwind CSS
- Vite
- React Icons
